# 📰 ГАЗЕТА ПОГОДЫ

Погодное приложение для Android, свёрстанное как ежедневная бумажная газета.
Фронтенд — HTML/CSS/JS в **WebView**, сборка APK — через **GitHub Actions**.

> **Скачать APK:** [последний релиз](../../releases/latest) → `WeatherGazette.apk`
> **Посмотреть в браузере:** https://gl1ch5.github.io/Apk/

---

## Что внутри номера

| Раздел | Содержание |
|---|---|
| **Передовица** | Текущая температура крупным шрифтом, погодный глиф, «журналистский» лид-абзац, собранный из данных (осадки, ветер, тренд на завтра, выходные), буквица, факты, 6 мини-заметок |
| **По часам** | 24 часа с прокруткой, кривая температуры и график вероятности осадков (SVG) |
| **Неделя** | 7 дней: день, описание, шкала min→max, вероятность дождя |
| **Сводка** | Ощущаемая температура, влажность, облачность, ветер и порывы, давление, осадки, УФ-индекс, восход/закат и альманах |

Дополнительно: **три печатных выпуска** (дневной / вечерний / ночной), **°C ↔ °F**, **поиск по городам мира**, **геолокация**, **офлайн-архив** последнего номера, pull-to-refresh, липкая строка-колонтитул.

## Источники данных (публичные API, без ключей)

- Прогноз: [Open-Meteo](https://open-meteo.com/) — `api.open-meteo.com` (CC BY 4.0)
- Поиск городов: `geocoding-api.open-meteo.com`
- Обратное геокодирование: `api.bigdatacloud.net` (fallback — координаты)

Сеть нужна только для получения свежего номера; вся вёрстка и логика лежат в APK.

## Как собрать

Сборка автоматическая — при каждом пуше в `main`:

```
.github/workflows/build-apk.yml
  → JDK 17 + Gradle 8.7 + AGP 8.5.2
  → :app:assembleRelease (если упадёт — fallback на debug)
  → артефакт WeatherGazette-APK-<sha> (90 дней)
  → GitHub Release build-<N> с файлом WeatherGazette.apk
```

Локально:

```bash
gradle :app:assembleDebug      # или ./gradlew, если обёртка установлена
# APK: app/build/outputs/apk/debug/app-debug.apk
```

### Подпись

- Если задать секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` — используется ваш ключ.
- Иначе workflow один раз генерирует постоянный ключ и сохраняет его в Actions Cache (`gazette-release-keystore-v1`), поэтому обновления APK ставятся поверх предыдущей версии.

> ⚠️ Для публикации в Google Play или если важна предсказуемая подпись — добавьте свои секреты keystore.

## Структура

```
app/src/main/assets/www/     # само приложение (HTML/CSS/JS)
app/src/main/java/.../MainActivity.java
                             # WebView: мост JS↔Kotlin, инсеты, разрешения,
                             # сете-монитор, кнопка «назад», жесты, тосты
app/src/main/res/            # иконка, splash-эмблема, темы, network config
docs/                        # копия для GitHub Pages (превью в браузере)
.github/workflows/           # сборка APK и релиз
```

## Разрешения

`INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_COARSE/FINE_LOCATION` (только по кнопке ◎), `VIBRATE`.
Клиртекст запрещён, разрешён только HTTPS с системными сертификатами.
